Move: frees download space immediately, but the original source copy disappears.

Copy: keeps the original intact, but doubles storage use.

Hardlink: keeps one physical copy, but requires source and destination on the same filesystem.

Symlink: keeps a pointer to the original file, which must stay available.

Collection imports are source-preserving and only apply these methods to the library artifact Pullbox creates.
